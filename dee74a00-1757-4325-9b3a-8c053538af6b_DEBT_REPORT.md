# DEBT_REPORT.md

## File: backend/app.py
- **Complexity/Debt:** The `app.py` file contains heavy ML model logic, geocoding logic, and API route definitions, all in one file. It relies on `joblib` and `sklearn` for model loading and prediction.
- **Refactoring Observations:** High coupling between the web server, geocoding service, and ML prediction logic. Should be separated into `services/`, `models/`, and `routes/`.
- **Missing Dependencies:** The following packages are required but NOT available in the sandbox: `joblib`, `sklearn`, `dotenv`. As a result, the backend cannot be fully tested in this environment.

## File: main.py
- **Complexity/Debt:** Minimal.
- **Observations:** Only a entry point.

## File: static/script.js
- **Complexity/Debt:** Minimal.
- **Observations:** Provides frontend interaction.

## File: services/location_service.py
- **Complexity/Debt:** Contains some geolocation utility.
- **Observations:** Could be further decoupled.
